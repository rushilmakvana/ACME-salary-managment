# AI Usage

Example instructions and prompts I used for improvements.

---

## Prompt 1

The first priority for this project should be:

- Any code or suggestions should be easy for human developers to understand, so they can review the code
  and give the AI feedback on changes. Prioritize a clean, simple workflow that human developers can follow,
  while keeping the code optimized.
- A meaningful set of unit tests that cover the core functionality.
- Tests that are fast, deterministic, and easy to understand.
- Good code structure, readability, and maintainability.

For each new change, explain what it is, why it is better, how it will affect the existing code and features,
and whether it is necessary.

We don't need to add anything extra for now.

You can suggest improvements to the code, the database design, the requirements, or anything important I'm missing.
